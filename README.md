# Portal de Migração - LEVE IA (V2)

Este repositório contém o front-end descentralizado para consulta de saldo de migração do token LEVE IA.

## Funcionalidades
- Conexão segura com Carteiras Web3 (MetaMask, TrustWallet, Rabby).
- Leitura direta do Smart Contract de Vesting na Binance Smart Chain.
- Interface transparente para holders verificarem sua alocação reservada.
